# Starcat 术语表

这个术语表用于统一 Starcat UI 和文档中的产品用语。

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| Starcat | 产品名，不翻译。 |
| GitHub Stars | 可按语境译为“GitHub Stars”或“GitHub 收藏”。不要译成“星星”。 |
| repository / repo | 统一译为“仓库”。空间很紧时也优先用“仓库”。 |
| Local-first | 译为“本地优先”。表示用户数据优先保存在本地，仓库缓存可重建。 |
| BYOK | 首次出现可写作“BYOK（使用自己的模型 Provider 或 API Key）”。 |
| Direct build | 译为“Direct 版本”或“Direct 构建”，表示从官网分发的非 App Store macOS 版本。 |
| Release | GitHub 场景译为“Release”或“发布版本”；应用发布说明中可译为“版本”。 |
| Changelog | 译为“更新日志”。 |
| CodeFlow | 功能名，不翻译。 |
| CodebaseMemory | 技术名，不翻译。 |
| OpenSSF Scorecard | 官方名称，保留英文。 |
