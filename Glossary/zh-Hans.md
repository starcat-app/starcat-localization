# Starcat 术语表

这个术语表用于统一 Starcat UI、文档、发布说明、支持 issue 和本地化贡献中的产品用语。

## 产品与分发

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| Starcat | 产品名，不翻译。 |
| Starcat Pro | 产品层级 / 公开支持仓库名，不翻译。 |
| Direct build | 译为“Direct 版本”或“Direct 构建”，表示从官网分发的非 App Store macOS 版本。 |
| App Store build | 译为“App Store 版本”，必须和 Direct 版本区分。 |
| Homebrew tap | 可写作“Homebrew tap”，指 `dong4j/homebrew-starcat` 仓库。 |
| Cask | Homebrew cask 包。提到 `Casks/starcat.rb` 时保留英文。 |
| Sparkle | 应用内更新框架名，不翻译。 |
| appcast | Sparkle 更新 feed。一般保留小写英文。 |
| Changelog | 译为“更新日志”。 |
| Release notes | 译为“发布说明”。 |
| Pro license | 译为“Pro 授权”或“Pro license”，仅在购买 / 授权流程中使用。 |
| Entitlement | 译为“权益”或“授权状态”，按上下文选择。 |

## GitHub 与仓库概念

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| GitHub | 产品名，不翻译。 |
| GitHub Stars | 可按语境译为“GitHub Stars”或“GitHub 收藏”。不要译成“星星”。 |
| Star / Unstar | GitHub 动作。可译为“收藏 / 取消收藏”，需要强调 GitHub 动作时保留 Star / Unstar。 |
| starred repository | 译为“已收藏仓库”或“Star 过的仓库”。 |
| repository / repo | 统一译为“仓库”。空间很紧时也优先用“仓库”。 |
| owner | 译为“所有者”，指 GitHub 账号或组织。 |
| topic | 译为“topic”或“主题”，GitHub topics 场景可保留英文。 |
| README | 保留大写英文，指仓库 README 文件或内容。 |
| GitHub Release | 译为“GitHub Release”或“仓库 Release”，不要混同为 App 版本。 |
| Issues | GitHub 场景可写作“Issues”或“问题”。 |
| Pull Request / PR | 首次出现可写“Pull Request（PR）”，空间紧时用“PR”。 |
| fork | GitHub 状态，通常保留英文或译为“Fork”。 |
| archived | 译为“已归档”。 |
| default branch | 译为“默认分支”。 |
| clone URL | 译为“clone 地址”或“克隆地址”。 |

## 整理与知识库

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| tag | 译为“标签”。指用户自定义 Starcat 标签。 |
| Tags | 译为“标签”。作为 UI 分区时也用“标签”。 |
| note | 译为“笔记”。 |
| private notes | 译为“私有笔记”。 |
| status | 译为“状态”，指未读、阅读中、使用中、已废弃等。 |
| smart collection | 译为“智能集合”。 |
| library | Starcat 语境译为“知识库”，不要译成“库文件”。 |
| import | 译为“导入”。 |
| export | 译为“导出”。 |
| JSON import/export | 译为“JSON 导入 / 导出”。 |
| cache | 译为“缓存”，指可重建数据。 |
| local data | 译为“本地数据”，指标签、笔记、状态、偏好等用户创建数据。 |

## 搜索与发现

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| Search Center | 功能名，译为“搜索中心”。 |
| full-text search | 译为“全文搜索”。 |
| FTS5 | SQLite 全文搜索引擎名，不翻译。 |
| semantic search | 译为“语义搜索”。 |
| embedding | 译为“embedding”或“向量表示”，按上下文选择。 |
| RRF | Reciprocal Rank Fusion。首次出现可补全称，通常保留 RRF。 |
| filter | 译为“筛选”。 |
| sort | 译为“排序”。 |
| Explore | Starcat 功能入口，译为“探索”。 |
| Trending | GitHub / Starcat 场景通常保留“Trending”。 |
| Discovery | 后端 / 功能名可译为“发现”或保留 Discovery。 |
| Weekly | 周刊来源，译为“Weekly”或“周刊”，按 UI 空间选择。 |
| recommendation | 译为“推荐”。 |
| similar repository | 译为“相似仓库”。 |

## AI 与代码智能

| 术语 | 推荐译法 / 说明 |
| --- | --- |
| AI | 保留大写英文。 |
| BYOK | 首次出现可写作“BYOK（使用自己的模型 Provider 或 API Key）”。 |
| provider | AI / 外部搜索服务商，通常保留“Provider”。 |
| API key | 写作“API Key”。 |
| token | 译为“Token”，不要和 API Key 混用，除非 UI 本身说的是 token。 |
| model | 译为“模型”。 |
| prompt | 译为“prompt”或“提示词”，按用户可见上下文选择。 |
| summary | 译为“摘要”。 |
| README translation | 译为“README 翻译”。 |
| chat | 译为“对话”。 |
| context | 译为“上下文”。 |
| Agent Workspace | 功能名，译为“Agent 工作台”。 |
| Built-in Agents | 译为“内置 Agents”或“内置代理”，当前产品语境优先用“内置 Agents”。 |
| artifact | 译为“产物”。 |
| CodeFlow | 功能名，不翻译。 |
| CodebaseMemory | 技术名，不翻译。 |
| code graph | 译为“代码图谱”。 |
| RAG | Retrieval-Augmented Generation。可写作“RAG”或“RAG（检索增强生成）”。 |
