# Starcat Glossary

This glossary records product terms that should stay consistent across Starcat UI and documentation.

| Term | Preferred Usage |
| --- | --- |
| Starcat | Product name. Do not translate. |
| GitHub Stars | Use as the GitHub feature name. Avoid shortening to only "stars" when the context may be unclear. |
| repository / repo | Use "repository" in formal copy and "repo" in compact UI when space is limited. |
| Local-first | User data is stored locally first; repo cache can be rebuilt. |
| BYOK | Bring your own key. In Starcat, this means users configure their own model provider or API key. |
| Direct build | The non-App-Store macOS build distributed from the Starcat website. |
| Release | A GitHub release or app release depending on context. Do not use "version" when referring to GitHub Releases. |
| Changelog | Release notes for Starcat. |
| CodeFlow | Starcat feature name. Do not translate. |
| CodebaseMemory | Technology name. Do not translate. |
| OpenSSF Scorecard | Security health signal. Keep the official name. |
